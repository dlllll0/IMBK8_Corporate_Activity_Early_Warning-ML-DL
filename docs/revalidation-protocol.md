# 사전 고정: 포트폴리오 보완용 재검증

2026-10-01. 이전 제출 모델의 동일 실행 복제가 아닌, 발견된 정보 시점 문제를 수정한 새 비교 실험.

- 대상: 2023.01–2025.05에 관측된 데이터만으로 누락 프로필 생성. 기존 완전 관측/중간 산발 누락 후보 규칙, 4업종, 2025.05까지의 마지막 업종을 사용. 이후 월 존재 여부로 후보를 선별하지 않음.
- 관측 누락 월의 거래건수를 0으로 채우지 않음. 현재 상태와 다음 달 상태를 비교할 때 필요한 8개 월(t-6..t+1)의 실제 관측 및 거래건수 가용성을 요구. 평가에서 제외된 관측 수를 공개.
- CV 기준은 대상 법인의 2025.05까지 계산 가능한 CV 평균으로 고정. 원본 -30% 또는 CV 초과 정의 유지. 실제 이탈/순수 미래 신규 사건 라벨로 바꾸었다고 주장하지 않음.
- 학습 X 2023.07–2025.05, validation X 2025.06–08, test X 2025.09–11. 월말 예측. 첫 validation 시점(2025.06 말)에 학습 목표 2025.06이 가용. 마지막 validation 목표 2025.09는 첫 test 예측월 말에 가용.
- 모형: LightGBM 원래 주요 하이퍼파라미터(500, .05, depth6, leaves31, seed42), 내부 거래만 사용. 외부 변수는 발표시점 미확인으로 제외. 원시 수치/보유구간·업종·지역, 예대/거래/카드/외환 합, 비중, 과거 lag·차분·이동통계. 모든 처리는 현재 및 과거 데이터만 사용. 숫자 결측은 LightGBM native missing 처리, categorical unknown 처리. 전처리 fit은 train만.
- 비교: 현재 상태 유지, 업종별 LightGBM 4개/통합/0.5블렌딩(라벨 재료 건수 제외), 통합 LightGBM에 현재 상태와 거래건수 이력 추가. 마지막 모형은 규칙에 이미 알려진 정보까지 제공했을 때 추가 가치가 있는지 확인하는 별도 실험.
- validation F1로 임계값 선택. test는 최종 평가, test 보고 신규 약화(현재0) recall와 F1, 상태 지속(현재1) 지표, 월별 F1. test 결과로 재튜닝 안 함.
- 월별 상위 500개 검토의 precision/recall도 계산. 단순 규칙의 동점 고객은 임의 ID순서 대신 동점 내 무작위 선정의 기대값으로 계산. 학습셋에 대한 성과는 보고하지 않음.
- 동일 test행의 법인 단위 bootstrap 300회로 모델 F1 - 상태 유지 F1의 95% percentile 구간. 신규 라벨 자체의 타당성/인과효과의 검증 아님.
- 고객군 비교: 별도 FINAL 군집 배정 유지, 2025.01–05 과거 예금+여신 규모(3개월 이상 관측)와 당시 마지막 업종으로 층 생성. 업종 내 규모 5분위. 2025.09–11 3개월 모두 관측된 법인 비교. 각 집단20개 이상인 공통 층만 사용, pooled strata weights로 표준화. 제외 인원·커버리지 명시. 인과적 조정/모든 교란 통제 아님.
- 원본·실데이터·행별 예측은 공개하지 않음. 코드와 집계 JSON만 공개. 모든 손익은 가정이며 재검증 점수를 금전 실적으로 변환하지 않음.
